One line of weather forecast, at most 140 characters, for a city that does not exist — written for the [make.fun bounty](https://make.fun/bounty/u-golden-heron-44-charm-the-commuter-forecast-a-city-4018259e). The program writes the forecast to `/output/entry.txt`:

> St. Jude-in-the-Fens: Heavy fog until dusk; do not touch the glowing green puddles outside the library.

Run it with Node 22: `node main.ts`
